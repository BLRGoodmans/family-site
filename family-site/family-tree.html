Import your GEDCOM file from Ancestry, MyHeritage, FamilySearch or Gramps to visualise the full family tree.

Upload your GEDCOM file

Drag & drop your .ged file here, or click to browse.
GEDCOM files can be exported from Ancestry, MyHeritage, FamilySearch, Gramps and most genealogy apps.

Files are processed locally in your browser — nothing is uploaded to a server.

📦 Ancestry

Tree Settings → Export Tree → Download GEDCOM

🌐 MyHeritage

Family Tree → Manage → Export to GEDCOM

⛪ FamilySearch

Family Tree → Person → Tools → Export GEDCOM

🖥 Gramps

File → Export → GEDCOM (.ged)
